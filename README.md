# Smart Vocabulary App

This project contains the privacy policy for the Smart Vocabulary App.

## Description

The Smart Vocabulary App is a mobile application designed to help users learn and expand their vocabulary.

## Privacy Policy

The privacy of our users is important to us. Our privacy policy outlines the types of information we collect, how we use it, and the steps we take to protect it.

You can view the full privacy policy by opening the `privacy.html` file in your web browser.

## How to View

1.  Clone or download this repository.
2.  Navigate to the project directory.
3.  Open the `privacy.html` file in a web browser of your choice.
